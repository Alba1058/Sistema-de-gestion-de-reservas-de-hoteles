# Sistema de Gestión de Reservas de Hoteles

Sistema desarrollado para la administración de reservas hoteleras, permitiendo gestionar clientes, habitaciones y reservas de manera eficiente.

## Características

* Registro y gestión de clientes.
* Administración de habitaciones.
* Creación, modificación y cancelación de reservas.
* Consultas de disponibilidad.
* Operaciones CRUD completas.
* Integración con SQL Server.

## Tecnologías Utilizadas

* C#
* .NET
* SQL Server
* Visual Studio

## Objetivo

Facilitar la gestión de información relacionada con reservas hoteleras mediante una aplicación que centraliza los procesos administrativos y mejora el control de las operaciones.
